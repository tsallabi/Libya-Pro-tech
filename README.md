# Libya Pro Tech — موقع الشركة

موقع ثابت (HTML/CSS/JS بلا أدوات بناء) لشركة ليبيا برو للتقنية.

**الموقع الحي:** https://libya-pro-tech.pages.dev — منشور من الفرع `main` تلقائياً عبر Cloudflare Pages.

- **تحليل 100 موقع عالمي وعربي والهوية المقترحة:** [docs/BRAND-ANALYSIS.md](docs/BRAND-ANALYSIS.md)
- **خطة المحتوى والعرض:** [docs/PLAN.md](docs/PLAN.md)

## الهوية
فاتح أحادي اللون: أرضية `#F3F5F9`، أسطح بيضاء، حبر `#0B0B0C`، والزر الأساسي أسود مصمت.
لا ألوان تمييز إطلاقاً — التباين وحده هو الهوية، والألوان الوحيدة في الصفحة تأتي من لقطات الأنظمة.
الخط: **Cairo** لكل النصوص. لا تدرجات، لا إيموجي، لا أيقونات جاهزة.

**الحركة:** شبكة نقاط خلف البطل تعبرها موجة حبرية كل 6.5 ثانية، دخول متدرج، خط تقدّم القراءة،
عدّادات، وتقريب اللقطة عند التحويم. كلها transform و opacity فقط، وتتوقف كلياً مع «تقليل الحركة».

## اللقطات
كل صورة في `assets/shots/` مُلتقَطة آلياً من النظام نفسه أثناء تشغيله محلياً بدقة 2× ثم حُوّلت إلى WebP.
نظام بلا لقطة يُعرض في «سجل الأنظمة» نصياً — لا تُستخدم صور بديلة أو وهمية إطلاقاً.

## إضافة نظام
سطر في `data/projects.json`:
`{"id","name","latin","tag","sector","desc","tech":[],"repo","demo","shot","shotAlt"}`
`shot` فارغ ⇒ يظهر في السجل النصي. `demo` فارغ ⇒ زر «تفاصيل العرض».

## النشر
Cloudflare Pages بلا خطوة بناء — التفاصيل في [docs/DEPLOY.md](docs/DEPLOY.md).

## تشغيل محلي
```
python3 -m http.server 8080
```

## خصوصية اللقطات
قبل نشر أي لقطة تحتوي بيانات عملاء حقيقية، تُموَّه الحقول الشخصية.
مثال مطبَّق: لقطة «أمان برو للتحويلات» مُموَّهة في كتلة إنذارات التأخير التي تحوي أسماء عملاء ومبالغ.

## سجل التمويه المطبَّق
- `amanpro-dashboard.webp` — كتلة إنذارات التأخير (أسماء عملاء ومبالغ)
- `mazadna-dashboard.webp` — اسم المستخدم المسجَّل
- `carrie-listing.webp` — اسم البائع في لوحة البائع
شاشات أخرى تحتوي أسماء أشخاص استُبعدت بالكامل بدل تمويهها: قوائم المركبات والفواتير والحاويات في مزادنا، وصفحة فريق العمل في Irish Castle.
