# Libya Pro Tech — موقع الشركة
موقع ثابت (HTML/CSS/JS) لشركة ليبيا برو للتقنية مع معرض Demo حي لكل منظوماتنا.
- الخطة الكاملة: [docs/PLAN.md](docs/PLAN.md)
