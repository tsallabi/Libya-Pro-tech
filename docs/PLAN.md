## 2) الخطاب التسويقي (Tone of voice)

- **العنوان الرئيسي:** «نبني المنظومات التي تُدير ليبيا الرقمية»
- **العنوان الفرعي:** «+30 منظومة وتطبيق مُنفَّذ — جرّبها الآن بنفسك، لا تكتفِ بالوعود.»
- **المبدأ:** لا نقول «نستطيع»، بل نقول «جرّب». كل خدمة نذكرها يقابلها Demo حي.
- **أدلة القوة (Proof points):** عدد المنظومات، سنوات الخبرة، مجالات: مصرفي / حكومي / تجاري / لوجستي / ذكاء اصطناعي.
- **دعوة للفعل الوحيدة (CTA):** «احصل على عرض سعر خلال 24 ساعة» + زر واتساب مباشر.

## 4) هيكل الصفحات

1. **الرئيسية** — Hero بعرض شاشات حقيقية متحركة، شريط ثقة (قطاعات)، خدمات، Portfolio مختصر، منهجية العمل، نموذج عرض سعر.
2. **الأعمال / Portfolio** — شبكة قابلة للتصفية (مصرفي، حكومي، متاجر، مزادات، لوجستيات، AI، خدمات). كل بطاقة: صورة، وصف، التقنيات، زر «جرّب الديمو» يفتح المنظومة في نافذة داخل الموقع (iframe) + زر «اطلب نسختك».
3. **صفحة تفاصيل المنظومة** — للمنظومات الكبيرة (MACCHINAA، AMANPRO، AUTOPRO): الشاشات، المزايا، الأدوار (مدير/موظف/عميل)، حسابات Demo جاهزة.
4. **الحلول القطاعية** — المصارف / الحكومة / التجار: لكل قطاع صفحة تُعيد ترتيب نفس المنظومات بلغة القطاع.
5. **عن الشركة** — فرع Egypt Pro Orspra، الفريق، طريقة العمل، الضمانات.
6. **تواصل / طلب عرض سعر** — النموذج نفسه المستخدم في الفوتر الموحد + واتساب.

## 6) طريقة عرض الديمو

- **داخل الموقع:** نافذة Modal بإطار iframe بحجم شاشة جوال/حاسوب (تبديل بزر) — يشعر الزبون أنه يجرب المنتج دون مغادرة الموقع.
- **حسابات Demo:** كل بطاقة تعرض بيانات دخول تجريبية (مدير / موظف / عميل) تُنسخ بضغطة.
- **إعادة تعيين يومية:** قاعدة كل Demo تُعاد لحالتها الأصلية يومياً حتى لا يفسدها المتصفحون.
- **علامة مائية:** شريط علوي داخل كل Demo «نسخة تجريبية — اطلب نسختك» يعود بالزبون لنموذج الطلب.

## 7) كيف نخترق البنوك والجهات الحكومية

1. **صفحة قطاعية مخصصة** لكل منها بلغتهم (امتثال، أمان، تقارير، صلاحيات).
2. **ملف تعريفي PDF قابل للتنزيل** يُولَّد من نفس بيانات الموقع.
3. **قسم «الأمان والامتثال»:** تشفير، نسخ احتياطي، سجل تدقيق، استضافة داخل ليبيا أو سحابة.
4. **دراسة حالة** لكل منظومة كبيرة: المشكلة → الحل → النتيجة بالأرقام.
5. **زر «اطلب عرضاً تقديمياً حضورياً»** يفتح نموذجاً مختصراً يُرسَل لك مباشرة.
6. **SEO عربي:** كلمات مثل «تصميم منظومة مصرفية ليبيا»، «برمجة تطبيق حكومي ليبيا».

## 8) التقنية والتنفيذ

- الموقع ثابت (HTML/CSS/JS) بلا بناء معقد — سريع، آمن، يُستضاف على Netlify/Cloudflare مجاناً.
- البيانات في `data/projects.json` حتى تُضاف منظومة جديدة بسطر واحد.
- نموذج الطلب يُرسل عبر Formspree/Netlify Forms أو Webhook لواتساب.
